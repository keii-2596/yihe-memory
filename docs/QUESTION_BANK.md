# Java 八股知识库

内置知识库目前包含 163 道卡片，覆盖 Java 基础、面向对象、集合框架、JVM、Java 并发、Java IO、Java 新特性、Spring、Spring Boot、MyBatis、数据库、Redis、消息队列、分布式和系统设计。

每张卡由问题、回答提示、评分点、参考答案、难度、标签和来源组成。评分点用于本地匹配和 AI 判题，参考答案用于用户自查；它们不是要求用户逐字复述的“唯一标准答案”。

应用升级到知识库 v3 时，会按稳定 ID 补充缺失的内置卡片，同时保留用户对现有卡片的修改和自定义卡片。用户主动删除内置卡片后，v3 内不会反复恢复。

新增卡片的质量标准见 [CONTRIBUTING.md](../CONTRIBUTING.md)。
