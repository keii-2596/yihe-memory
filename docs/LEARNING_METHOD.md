# 学习机制说明

忆核把开放式面试题当作“需要主动提取的记忆卡”，但不会把参考答案当成唯一标准表述。

## 一次复习如何进行

1. 首屏只显示题目，用户先独立回忆并用文字或语音作答。
2. 想不起来时，可以主动展开一条提示。
3. 仍然想不起来时，再查看参考答案；这次不进行 AI 打分，而是按“忘记”记录，稍后重新出现。
4. 正常提交答案后，由 AI 或本地规则评估覆盖点，再由用户选择“忘记 / 困难 / 掌握 / 简单”。

这种设计参考了 Anki 的“先看问题、主动回忆后再显示答案”流程，同时避免用户先看到提示造成虚假的熟悉感。

## 每日任务如何组成

- `每日复习上限`：限制当天最多处理多少次已到期复习。
- `每日新学上限`：限制当天最多首次学习多少个知识点，可以设为 0 暂停新学。
- 任务始终先安排到期复习，再按当前学习词书引入新知识。
- 每个知识主题可包含定义、机制、边界、排障与落地等关联卡；同一主题每天只安排一张，答完后其余关联卡自动错开到后续日期，减少相邻题互相提示造成的虚假熟练。
- 如果到期复习已经超过每日复习上限，系统会暂停当天新学，避免复习债务持续扩大。
- 没完成的到期内容不会消失，会在后续日期继续优先出现。

这套策略参考了 Anki 对新卡与复习的独立限额，以及墨墨“先复习、再新学”的任务顺序。

## 卡片控制与自定义学习

这些基础能力全部免费，并且不会强制用户理解复杂参数：

- `撤销上次复习`：恢复这次评分前的进度和到期时间；第一次学习也可以撤销为未学习。
- `今天不再出现`：只把卡片隐藏到第二天零点，原复习记录和到期时间保持不变。
- `暂停`：卡片一直离开每日队列，直到用户在知识题库中手动恢复。
- `反复遗忘`：累计忘记至少 4 次时给出提醒和筛选入口，但不会自动暂停，避免系统替用户做决定。
- `自定义学习`：可集中处理到期、反复遗忘、收藏、提前复习、新题或随机题；“仅练习”模式不写历史、不改变原计划。

这里借鉴了 Anki 的撤销、bury、suspend、filtered deck 与 leech 思路，但用更直白的中文和更少的设置项呈现。面试知识往往比单词更大，因此反复遗忘提醒也会建议拆题或补充前置知识，而不是只增加重复次数。

## 学习词书会影响什么

学习词书会影响：

- 首次引入的新知识范围；
- 新知识的分类顺序；
- 模拟面试的抽题范围；
- 路线页的已学进度和预计完成天数。

学习词书不会隐藏已经学过且到期的复习题。即使切换词书，旧词书中已学习的内容仍会按期出现，避免因为换方向而丢失记忆维护。官方词书保持只读；可以复制成自定义词书，再自由改名、增删或编辑其中的知识点。JD 与面试复盘也可以直接生成新的个人词书。

## 面试倒计时如何工作

在学习词书页设置面试日期后，系统会根据当前词书的剩余新题、已经到期的复习、每日新学上限、每日复习上限和可用时间生成计划：

- 正常学习期：按剩余学习日均摊新主题，同时维护 FSRS 到期复习；
- 追赶期：当剩余任务超过当前上限或可用时间时，明确显示“需要追赶”，优先清理积压；
- 最终复习期：默认在面试前 4 天停止引入新题，补充抽取已学但薄弱的主题；
- 面试日：不再引入新知识，只保留轻量回忆。

开启“让计划自动调整每日队列”后，倒计时给出的新学与复习目标会真正替换普通每日上限。关闭后仍可查看计划，但每日队列继续使用手动设置。

## 面试复盘与 Prompt

面试复盘接受录音或文字稿。录音只用于当次转写，不长期保存；云同步保留复盘结论、行动计划和生成题目，不保存完整文字稿。设置页的 Prompt 工作台可以分别调整 AI 判题、追问、材料制卡、JD 词书、录音转写和面试复盘的提示词。

## “预计记住率”如何计算

它不是 MOOC 数据，也不是其他用户的平均数据。新题在首次学习前显示“未学习”，没有虚构的初始百分比。

完成第一次学习后，系统根据当前用户自己的记录估算：

- 距离上次复习过去了多久；
- 当前知识点的记忆稳定性；
- 历次选择的“忘记 / 困难 / 掌握 / 简单”；
- AI 或本地评估分数；
- 用户设置的目标记忆率。

当前调度使用开源 `ts-fsrs` 的标准 FSRS-6 实现。每张卡保存自己的难度、稳定性、可提取性、学习状态、遗忘次数和短期学习步骤；目标记忆率会直接影响下一次间隔。升级前的学习记录会映射到这些字段，不需要清空进度。调度完全在本地运行，不使用其他用户或 MOOC 的群体数据；参数优化器暂未启用。

学习词书页还会显示未来 30 天工作量：紫色是已由 FSRS 排定的复习，绿色是面试倒计时计划准备引入的新知识。它是计划预估，不代表未来任务不会随着实际评分而变化。

“长期掌握”采用更严格的口径：记忆稳定期至少达到 21 天，且最近一次回答得分不低于 70 分。
