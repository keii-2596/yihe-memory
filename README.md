# 忆核

面向计算机面试知识的间隔重复学习应用。用户可以用文字或浏览器语音输入回答开放题，系统从概念覆盖、逻辑准确和表达清晰三个维度评估，并根据自评结果安排下一次复习。

## 已包含

- 12 道计算机面试示例题，覆盖数据库、网络、操作系统、Java、算法、前端和系统设计
- 完整的题库新增、编辑、删除、搜索和分类筛选
- 文字与浏览器语音回答
- 服务端 AI 判题代理，以及无需密钥的本地评分回退
- 类 SM-2 的四档复习调度：忘记、困难、掌握、简单；只在到期时重新进入今日队列
- 当前设备持久保存题库、进度和复习历史，并支持 JSON 导入导出备份
- 根据真实记录生成连续学习天数、14 天活动图、分类掌握度和薄弱项
- 桌面、平板和手机响应式界面

## AI 接口

复制 `.env.example` 为 `.env.local` 并配置服务端环境变量。接口默认兼容 OpenAI Chat Completions：

- `AI_EVALUATION_ENDPOINT`
- `AI_EVALUATION_API_KEY`
- `AI_EVALUATION_MODEL`
- `NEXT_PUBLIC_SITE_ORIGIN`（部署后的可信站点地址，用于分享卡片）

浏览器只请求站内的 `POST /api/evaluate`，不会接触 API 密钥。如果没有配置外部模型，接口会自动使用本地核心概念覆盖算法，便于直接运行和演示。

`GET /api/evaluate` 只返回当前评估模式与模型名称，不返回任何密钥。

## 数据说明

当前版本是无账号的单人学习工具，题库和学习记录保存在浏览器本地。可在“AI 与数据”页面导出完整 JSON 备份，并在其他设备导入恢复。
